# Frozen VAMM MVP Implementation Plan

> **For agentic workers:** Execute the existing approved worker briefs in parallel under AGENTS.md. No recursive delegation.

**Goal:** Build the accepted five-screen, three-turn educational MVP without changing contract v2 or the fixture manifest.

**Architecture:** A Next.js app consumes immutable synthetic market/news fixtures and a browser-local gateway. A pure engine supplies previews and turns; IndexedDB atomically persists state/history/replay. Research alone has a server model path with a labeled prewritten fallback.

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind 4, Lucide, Recharts, TanStack Query, Zod, Vitest, fake-indexeddb, Playwright.
**Spec:** docs/MVP.md, src/contracts/README.md, docs/FIXTURES.md, orchestration/briefs/VAMM-{UI,DATA,SIM}-01.md.

## Global constraints

- Contract version 2, dataset vamm-demo-2026-11-06.v1, calculation vamm-calc.v1.
- Zero initial holdings; ages 15 to 18 in three deterministic annual turns.
- Browser-local IndexedDB, explicit shock funding, preserved history on reset.
- Preview and ADVANCE share pure contribution math; no UI financial formulas.
- Five existing routes; deferred Academy, stock trading, XP, profiles and live news stay excluded.
- Original IDENTITY, SOUL, USER and accepted frozen specification files remain untouched.

## Review focus

- Late replay/reset responses must not replace newer active state.
- Concurrent tab writes must not both commit against one version.
- Corrupt/unavailable storage must display failure without silently recreating a session.
- Shock settlement must never repeat contributions, returns, inflation or earlier turns.
- Research output must not fabricate evidence or alter financial state.
