## Three recommended combinations

1. **The quiet helix:** VAMM green, light density, unhurried axial roll. Best reference adaptation for occasional restoration or a small loading panel. It remains recognizable when static. Use only while a real request is pending.
2. **The evidence orbit:** Charcoal, compact, light density and restrained motion. Suitable for a research-response wait with one concise status, without promising undisclosed research tools.
3. **The settled signal:** Warm ivory, a neutral line resolving to a static check only after a real commit. Show the real result immediately; optional opacity settling should stay around 150–180 ms.

News can reuse the same skeleton/particle language. Stable article identity, source links, readable text and explicit provider hide/pause behavior remain more important than decoration. For the current TradingView feed, VAMM controls the outer host/loading/error/hide boundary only. Row19 is adapted to outer-host arrival; no per-card reordering or closed-shadow inspection, scraping, ingestion API or new store is authorized.

## Future presentation boundary

The shared production motion API consumes label and idle/loading/ready/error state, with decoration-only replay keys. This presentation boundary does not amend contract v2.

- Existing query pending/error state drives decoration. Decoration never starts a fetch.
- Existing simulation busy/result/error state drives acknowledgment. Replaying a visual must not reinitialize hooks, change request IDs, or call create/ADVANCE/SETTLE/reset.
- TradingView's real ready/error events remain authoritative.
- Pausing artwork does not pause a financial transaction. Hiding a provider is a separate, explicit operation.
- No forced splash delay, fabricated percentage, financial count-up, or animation-triggered state transition.
- Preserve validation, disabled/pending controls, conflict/replay handling, provenance, keyboard focus and visible errors when teammate UI replaces presentation.

## Accessibility / implementation

React, DOM/SVG and CSS only. Loops use transform/opacity, and particle morphing changes transformed coordinates instead of layout dimensions. Runtime OS preference changes use useSyncExternalStore. Scoped CSS immediately disables animated loops and morph transitions for reduced motion. Manual static mode cannot override the OS preference; its switch reflects effective static state and is disabled when system preference controls it.

Pause holds current CSS play state. Replay remounts only the decorative subtree, retaining selections and explicit sample state. Artwork is hidden from assistive technology; concise sample-state text is announced. Controls are semantic, labeled, focus-visible and at least 44px tall. No global body styles are included.
